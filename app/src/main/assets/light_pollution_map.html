Einordnung, Datenstand und Quellen

Raster-Klassen sind eine unvalidierte Orientierung aus dem dargestellten Nachtlicht: Index <3 → 1, <7 → 2, <13 → 3, <22 → 4, <35 → 5, <50 → 6, <68 → 7, <85 → 8, sonst → 9. Die grobe Zuordnung zum Bortle-Schema ist keine gemessene Bortle-Klasse.

Wenig Licht im Bild garantiert keinen dunklen Himmel. Lichtglocken aus der Umgebung, Wolken, Mond, Schnee, Gelände und neuere Bebauung können die Bedingungen stark ändern. Schwarze gültige Bildpixel zählen als Index 0; transparente oder fehlende Pixel sind „Keine Daten“.

Eine Auswertung mittelt gültige Pixel in einem 9 × 9-Fenster einer NASA-Kachel auf Datenzoom 8. Bei starkem Zoom werden Bildpixel nur vergrößert; die Datengenauigkeit steigt dadurch nicht. Raster-Klassen erscheinen nur an ausgewerteten Punkten.

Abruf: noch keine Kachel empfangen. Abrufzeit und Beobachtungsjahr sind verschieden.
